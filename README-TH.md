# Freebuff AI ภาษาไทย 🇹🇭

แปล **ตัวโปรแกรม Freebuff Desktop** ให้เป็นภาษาไทยครบทั้งสองชั้น

1. **หน้าจอในแอพ** (UI) — พจนานุกรมรวม **1,678 คำ** + **267 รูปแบบข้อความอัตโนมัติ** + 9 วลี
   รวมทั้ง **คำอธิบาย (ทูลทิป) ของสกิลทุกตัว** ภารกิจ และระดับการคิด (reasoning effort)
   ตลอดจนข้อความที่โปรแกรมอ่านหน้าจออ่านออกเสียง (aria-label/data-tooltip) แบบที่มีชื่อ/ตัวเลขอยู่ในข้อความ
2. **เมนู native ของ Electron** (File / Edit / View / Window / Help ที่โผล่ตอนกด Alt)
   และกล่องข้อความ/ไดอะล็อกของโปรแกรม — อยู่ในชุดเดียวกัน (เพิ่มอีก 70 คำ รวมเป็น 1,748 คำที่ไม่ซ้ำ)

> ตรวจสอบล่าสุดกับแอป **Freebuff Desktop v0.0.114** — หน้าจอที่แปล: งาน/บทสนทนา, แท็บและพื้นที่,
> สกิล/ภารกิจ, สลับผู้ให้บริการ–โมเดล (BYOK), พื้นที่ทำงานแบบแยก, เซสชัน/โควตา/สปอนเซอร์,
> ตั้งค่า/คอนเน็กเตอร์, กล่องอนุมัติผู้ดูแลระบบ

ใช้วิธี "พจนานุกรม + ตัวแปลขณะรัน" จึง**ไม่พังเมื่อแอพอัปเดต** และ**ถอดออกได้ทุกเมื่อ**
แปลเฉพาะ *ข้อความของโปรแกรม* ไม่แตะโค้ด โปรเจกต์ หรือข้อความที่คุณพิมพ์

---

## วิธีใช้ (ง่ายที่สุด)

ดับเบิลคลิก **`Freebuff-TH.cmd`** — สคริปต์จะตรวจว่าการแปลลงครบหรือยัง (ถ้าแอพเพิ่งอัปเดต จะติดตั้งให้ใหม่) แล้วเปิดแอพให้

### Freebuff Manager (หน้าต่างจัดการแบบ All-in-one)

ดับเบิลคลิก **`Freebuff-Manager.cmd`** เพื่อเปิดศูนย์จัดการสำหรับ Windows 10/11 ซึ่งรวม:

- ติดตั้ง อัปเดต ตรวจสถานะ เปิด และถอดภาษาไทย
- ปรับขนาดตัวอักษรแยกเป็นภาพรวม คำอธิบาย ทูลทิป และปุ่ม/ช่องกรอก (75–160%)
- โหมดเชื่อมสเกลอัตโนมัติ ซึ่งเลื่อนภาพรวมครั้งเดียวแล้วปรับทุกกลุ่มตามกัน
- ดู เปิด และอัปเดตแอปโคลน โดยใช้ clone engine ที่บรรจุมากับ Freebuff Manager
- เก็บช่องทาง manifest สำหรับอัปเดตออนไลน์ในอนาคต พร้อมบังคับข้อมูลเวอร์ชัน ลิงก์ และ SHA-256

หลังเปลี่ยนขนาดตัวอักษร ให้กด `Ctrl+R` ใน Freebuff ที่เปิดอยู่ หรือปิดแล้วเปิดใหม่หนึ่งครั้ง

ถ้าเปิดแอพด้วยไอคอนปกติแล้วยังเป็นอังกฤษ ให้ปิดแอพแล้วเปิดใหม่ด้วยไฟล์นี้หนึ่งครั้ง (หรือกด `Ctrl+R` ในหน้าต่างแอพ)

## คำสั่งที่มีให้ใช้ (สำหรับสายเทคนิค)

เปิด Command Prompt ในโฟลเดอร์ `Freebuff AI TH` แล้ว:

| ต้องการ | คำสั่ง |
|---|---|
| ติดตั้ง/ซิงค์ภาษาไทยลงแอพทุกตัว (ตัวหลัก + สำเนา A–G) | `node fbth/fbth.js install` |
| ดูสถานะว่าติดตั้งแล้วหรือยัง | `node fbth/fbth.js status` |
| ถอดภาษาไทยออก คืนค่าเดิม | `node fbth/fbth.js uninstall` |
| ทดสอบตัวแปลในเบราว์เซอร์ | `node fbth/fbth.js bench` แล้ว `node dev/serve.js` → เปิด http://127.0.0.1:8791/ |
| ติดตั้งเฉพาะเมนู native (ที่ไม่ใช่ UI) | `node fbth/fbth.js install-shell` |
| ดู log ว่าเมนูถูกแปลเป็นอะไร | `node fbth/fbth.js shell-log` |
| ตรวจว่าพจนานุกรมยังตรงกับแอพ | `node fbth/tools/check-dict.js` |
| ดูคำอธิบายสกิลทั้งหมดที่แปลไว้ (และที่ยังขาด) | `node fbth/tools/extract-orchestrator-strings.js --list` |
| ทดสอบตัวแปลในเบราว์เซอร์แบบไฟล์เดียวจบ | `node fbth/fbth.js bench` แล้วเปิด `dev\bench-inline.html` |
| ดูค่า fuses ของแอพ (ว่าอะไรแก้ได้/ไม่ได้) | `node fbth/tools/read-fuses.js` |
| สร้าง "ชุดติดตั้งภาษาไทย" สำหรับส่งให้เพื่อน/เครื่องอื่น | `node fbth/tools/build-pack.js` |
| ทดสอบติดตั้ง/ถอด แบบไม่แตะแอพที่ใช้อยู่ | `node dev/selftest-pack.cjs` |

## ส่งให้คนอื่น (ชุดติดตั้งไทย)

```
node fbth/tools/build-pack.js
```
จะได้โฟลเดอร์ `build\Freebuff-Thai-Pack` และไฟล์ `build\Freebuff-Thai-Pack-v4.zip` (~143 KB) ส่งให้เพื่อนได้เลย
เครื่องปลายทาง **ไม่ต้องมี Node.js** และไม่ต้องมีโปรเจกต์นี้ — แค่มีแอพ Freebuff ติดตั้งอยู่แล้ว
แล้วดับเบิลคลิก `ติดตั้งภาษาไทย.cmd` (รายละเอียดอยู่ใน `README-ไทย.md` ของชุดนั้น)

ก่อนส่งทุกครั้ง แนะนำรัน `node dev/selftest-pack.cjs` หนึ่งรอบ
ตัวทดสอบจะสร้างแอพปลอมไว้ใน `dev\.selftest\` แล้วลองติดตั้ง/ถอดกับแอพปลอมเท่านั้น
จึงยืนยันได้ว่า "ถอดแล้วแอพกลับไปเดิมเป๊ะ" โดยไม่แตะแอพที่คุณใช้อยู่จริง

## ปรับ/เพิ่มคำแปลเอง

คำแปลอยู่ในโฟลเดอร์ `fbth/dict/` ไฟล์ JSON แก้ได้ด้วย Notepad หรือ VS Code:

```json
{
  "strings": { "New thread": "เธรดใหม่" },
  "patterns": [{ "from": "{n:num} files", "to": "{n} ไฟล์" }]
}
```

- `strings` = ข้อความตรงทั้งก้อน (ตัวแปลจะตัดช่องว่างหัว-ท้ายให้ก่อนเทียบ)
- `patterns` = ข้อความที่มีตัวเลข/ตัวแปร ใช้ `{ชื่อ}`, `{ชื่อ:num}`, `{ชื่อ:word}`
- `phrases` = แทนที่กลางข้อความแบบจับเป็นคำ (ใช้น้อย ๆ)

แก้เสร็จแล้วสั่ง `node fbth/fbth.js install` → กด `Ctrl+R` ในแอพ ก็เห็นผลทันที (ไม่ต้องปิดแอพถ้าแค่ซิงค์พจนานุกรม)
หรือจะเพิ่มคำแบบเห็นทันทีในแอพก็ได้: กด `F12` → Console → `fbth.reloadDict()`

## หาคำที่ยังไม่แปล (วิธีที่สะดวกที่สุด)

ในหน้าต่างแอพ กด `F12` แล้วพิมพ์:

```js
fbth.panel()               // เปิดแผงแสดงคำอังกฤษที่ยังไม่ถูกแปล + ปุ่มคัดลอก
```

หรือ `fbth.downloadCandidates()` เพื่อดาวน์โหลดเป็นไฟล์ JSON เอาไปให้ AI แปลต่อได้เลย

## คำถามที่พบบ่อย

**ต้องปิดแอพก่อนติดตั้งไหม?** ไม่ต้อง — แก้ไฟล์ได้ทันที แต่ต้อง `Ctrl+R` หรือปิด-เปิดแอพใหม่จึงเห็นผล

**มีผลกับโปรเจกต์/บทสนทนาของผมไหม?** ไม่มี — เราแตะเฉพาะไฟล์หน้าจอของแอพ (`resources/orchestrator/ui/`)
และสำรองต้นฉบับไว้เป็น `index.html.fbth-original` เสมอ

**แอพอัปเดตแล้วภาษาไทยหาย** เป็นเรื่องปกติ เพราะไฟล์ถูกแทนที่ทั้งชุด — แค่เปิดแอพด้วย `Freebuff-TH.cmd` อีกครั้ง
(พจนานุกรมต้นทางอยู่ในโฟลเดอร์นี้ ไม่หายไปไหน) หากถ้อยคำเดิมถูกเปลี่ยน จะมีคำใหม่ให้แปลเพิ่ม — ดู `HANDOFF.md` ข้อ 5

**จะถอดภาษาไทยออกทั้งหมด?** `node fbth/fbth.js uninstall`

**มีผลกับสำเนาแอพ (clones) ด้วยไหม?** มี — คำสั่ง `install` จะติดตั้งให้ทุกที่ติดตั้งที่เจอบนเครื่องนี้

**ทูลทิปในแท็บ “สกิล” / ภารกิจ เป็นไทยแล้วหรือยัง?** เป็นแล้ว — รวมทั้งสกิลที่แอพไม่มีคำอธิบายสั้น (เช่น review/test/commit)
ซึ่งแอพจะใช้ย่อหน้าแรกของคำสั่งภายในมาตัดที่ 220 ตัวอักษร รวมถึงทูลทิปของภารกิจ (autorun/merge-local/preview)
ถ้าแปลไม่ขึ้น ให้ตรวจด้วย `node fbth/tools/check-dict.js`

**มีอะไรที่ตั้งใจไม่แปลไหม?** มี — ชื่อรุ่นโมเดล/แบรนด์ (เช่น Claude, Gemini, Solar Pro), ชื่อสกิลสั้น ๆ (review/test/commit),
ชื่อธีมของตัวแก้ไขโค้ด, คำสั่งที่ให้คัดลอกไปรัน และข้อความภายในของไลบรารี — รายการทั้งหมดอยู่ใน
`fbth/dict/ignore.json` พร้อมเหตุผลรายข้อ (และข้อความโฆษณาที่เซิร์ฟเวอร์ส่งมา แปลได้เฉพาะส่วนที่กดได้)

**เมนูด้านบนยังเป็นอังกฤษ?** กด `Alt` เพื่อดูเมนู — ถ้ายังเป็นอังกฤษ ให้ปิดแอพแล้วเปิดใหม่
(เมนูถูกแปลตอนแอพเริ่มทำงาน ต้องรีสตาร์ทเท่านั้น) ถ้าต้องการยืนยันว่าทำงาน ให้ดู `node fbth/fbth.js shell-log`

**ถ้าแก้ clone ด้วยสคริปต์เดิม (`Manage-Freebuff-Clones.ps1`) จะเป็นอย่างไร?**
สคริปต์นั้นจะ repack `app.asar` ของ clone ใหม่ (จากโฟลเดอร์ `resources/app`) ทำให้การแทรกของเราหายไป
→ เปิดแอพด้วย `Freebuff-TH.cmd` อีกครั้ง หรือสั่ง `node fbth/fbth.js install` เพื่อติดตั้งกลับคืน
